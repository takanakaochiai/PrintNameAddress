# 帳票差し込み印刷

Windows 11（x64）で、同梱の `runtime` フォルダーがある場合は `PrintNameAddress.cmd` をダブルクリックすると起動します。

GitHubからソースを取得した場合は、Windows用のPython 3.12（Tkinter付き）をインストールし、アプリのフォルダーで次を実行してください。

```powershell
py -3.12 -m pip install Pillow pypdfium2
py -3.12 PrintNameAddress.pyw
```

1. 「PDFを開く」で入力欄のあるPDFを開きます。
2. 「CSVを開く」でCSVを選びます。UTF-8とCP932に対応しています。1行目に列名を記載してください。
3. 上部の「名前」から印刷する行を選びます。右隣の欄で、名前一覧に使うCSV列を変更できます。
4. 「列の対応表…」でPDF入力欄とCSV列を確認・編集します。PDF入力欄を選ぶと青枠が表示されます。対応を解除するにはCSV列を空欄にします。
5. 選んだ人を印刷するには「印刷…」、CSVの全員を印刷するには「全員を印刷…」を押します。Windowsの印刷画面でプリンターとページ範囲を選びます。全ページが初期設定です。一括印刷ではCSVの順番で1人分ずつ並び、ページ範囲は全員分を通したページ番号で指定します。

対応表はPDFと同じフォルダーに、同じファイル名の `.rl`（UTF-8のJSON）として保存します。お使いのPDFとCSVを用意し、初回は「列の対応表…」で項目を設定してください。

入力対象はPDFのAcroFormテキスト欄とコンボボックスです。扶養控除等申告書の生年月日は元号・年・月・日に分けて差し込みます。差し込んだ内容はアプリのプレビューと印刷に反映され、元PDFとCSVは読み取り専用で扱います。印刷には300 dpiで描画したページを使用します。
